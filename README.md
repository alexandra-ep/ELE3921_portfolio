# ELE3921_portfolio | ELEVATE
ELEVATE is a Django web application for managing fitness class bookings. The system allows users to browse upcoming fitness classes, register and log in, book classes, cancel bookings, and view both upcoming and past bookings. Admin users can manage instructors, locations, class categories, scheduled fitness classes, and bookings through the Django admin panel.

This project was developed for ELE3921 - Web Applications Development at BI Norwegian Business School, Spring 2026.

### Features
- User registration, login, and logout
- User profile update for first name, last name, email, and password
- Browse upcoming fitness classes
- Filter classes by category, location, and date
- View class details, instructor, location, time, duration, and availability
- Book available classes
- Cancel active bookings before the cancellation deadline
- View upcoming and past bookings
- Admin management for instructors, locations, class categories, class types, fitness classes, and bookings
- Responsive design for desktop and mobile

### Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Pillow

## Installation and Setup
1. Clone the repository or download the project folder.
2. Open Anaconda Prompt and navigate to the folder containing manage.py.
3. Install the required packages.
4. Apply migrations.
5. Load the included data file.
6. Start the development server.
7. Open the project in your browser.
